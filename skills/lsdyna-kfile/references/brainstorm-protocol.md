# 需求头脑风暴与收敛协议（阶段 1）

目标：把一个模糊想法收敛成一份**《仿真任务书》（spec.md）**——它是后续资料查找、
建模、验证、交付的唯一契约。任务书没确认之前，不写任何一张关键字卡。

## 1. 触发与跳过

- **触发**：用户输入缺失收敛清单中任何**标 ✦ 的关键项**（以 §2 表格为唯一权威口径：
  工况类型、分析目的与关注输出、几何与尺寸、材料、边界约束、初始条件、单位制），
  或用户明确表达"我有个想法/帮我想想怎么做"。
- **跳过**：用户输入已能落实全部关键项 → 只把非关键缺项按工程默认补齐，
  在任务书里标注 `[默认]`，展示一次确认后直接进入阶段 2。
- **交互不可用时**（子代理批处理、定时任务等无人值守场景）：不阻塞等待，
  全部缺项取推荐默认收敛，任务书里逐条标注 `[假设]`，并在最终交付报告里显著提示。

## 2. 收敛清单（12 项）

| # | 项 | 关键? | 说明 |
|---|---|---|---|
| 1 | 工况类型 | ✦ | 六大类（跌落/碰撞/侵彻/成形/ALE/SPH）或其组合 |
| 2 | 分析目的与关注输出 | ✦ | 变形/应力/加速度峰值/吸能/穿透判定/成形质量……决定输出卡和网格密度 |
| 3 | 几何与尺寸 | ✦ | 每个部件的形状与关键尺寸 |
| 4 | 网格来源与密度 | | gen_mesh 原语自动生成 / 用户提供 .k 网格 / 混合；目标单元尺寸 |
| 5 | 材料 | ✦ | 每个部件；先对材料库（materials.json），库里没有再查手册/文献 |
| 6 | 载荷 | | 重力、压力、强制运动等（跌落类默认含重力） |
| 7 | 边界约束 | ✦ | 每个部件约束在哪、约束哪些自由度。自由飞行体（跌落物等）可自动判定为"无约束"，面板回显即可，不占提问名额 |
| 8 | 初始条件 | ✦ | 初速度/角速度（或由跌落高度换算） |
| 9 | 接触关系 | | 谁和谁接触、摩擦系数（默认 0.2，成形 0.12） |
| 10 | 单位制 | ✦ | m-kg-s / mm-ton-s / mm-kg-ms / cm-g-us。**可默认的关键项**：用户不指定时取 mm-ton-s 并在任务书显式声明即视为满足，不必追问 |
| 11 | 终止时间 | | 按事件时长估 2~3 倍；宁短勿长，先跑通再加长 |
| 12 | 规模与精度预算 | | 可接受单次算多久、**交付期限**、sp/dp、SMP/MPP；决定网格密度上限 |

✦ = 关键项。关键项不允许无中生有地猜，必须问到或用户明确授权"你定"
（无人值守场景除外，按 §1 取推荐默认并标 `[假设]`；#7/#10 的自动判定/可默认情形见表内注）。

## 3. 提问规则（收敛循环）

1. **每轮最多 4 个问题**，按"分叉最大优先"排序：工况类型 → 物理要素（几何/材料/载荷/边界/初速）→ 数值参数（单位制/时长/规模）。不要一次抛出十几个问题。
2. **每个问题给 2~4 个带工程默认值的选项**，推荐项放最前并标"(推荐)"；
   在 Claude Code 中用 AskUserQuestion 工具（多个问题合并进一次调用）；
   Codex 或无该工具的环境用编号列表提问，请用户按编号回答。
3. 用户答"默认 / 你定 / 都行" → 取推荐值，任务书中标 `[默认]`。
4. **当场做量级体检**：用户给的数值立即用单位制换算核对
   （如用户在 mm-ton-s 语境下说密度 7850 → 马上指出该单位制下应为 7.85e-9 并确认其本意）。
   发现互相矛盾的输入（如"1kg 的球直径 10mm 的钢球"→ 密度对不上）当轮指出；
   简化建模的质量-几何一致性检查见 §4.1。
5. **每轮结束回显收敛面板**：
   ```
   ✅ 已确认: 工况=跌落; 铝板 150×150×2; ...
   🔶 已取默认待认: 摩擦 0.2; 单位制 mm-ton-s
   ❓ 下轮要问: 跌落高度; 关注指标
   ```
   12 项全部落实后，面板以"✅ 全部收敛——生成任务书，进入确认门"收尾。
6. **最多 5 轮**。第 5 轮结束仍有未决项 → 全部取默认，汇总为一次性确认。
7. 用户中途推翻已确认项是正常的——更新面板，不重复追问已确认项。

## 4. 专项子协议

### 4.1 几何来源分叉（收敛第 3/4 项时使用）

四条路，按此优先级与用户对齐：

1. **原语直出**：几何本身就是板/块/圆柱/球 → `gen_mesh.py` 直接生成。
2. **原语组合简化**（真实产品最常用）：把产品拆成原语组合。跌落/冲击类范式：
   外壳 = plate 拼盒或 box、关注件 = 局部加密的壳、内部质量 = 刚体块配重补足总质量、
   次要结构（机臂/凸台/圆角/紧固件）删除并把质量并入配重。**简化方案要点必须向用户展示确认**。
3. **用户供网格**：型面复杂且用户有 CAD/网格 → 请提供含 *NODE/*ELEMENT 的 .k 文件。
4. **混合**：关键件用户供网格 + 周边原语简化。

gen_mesh 可用原语：`plate`（壳板）/ `box`（实体块）/ `cylinder`（实体圆柱）/
`cylshell`（圆柱壳面）/ `sphere`（实体球）/ `sphbox`、`sphcyl`（SPH 粒子填充）；
圆柱类支持 `--axis x|y|z`，壳类支持 `--flip-normal`。

**质量-几何一致性体检（简化建模必做）**：Σ(部件体积×密度) 对比用户报告的总质量，
差额并入刚体配重（反算密度写进任务书部件表的"质量"列）；对不上又没有配重可加时当轮向用户指出。

### 4.2 库外材料子协议（材料不在 materials.json 时）

脑暴阶段就要闭环，不许留到建模阶段自由发挥：

1. 当场给出拟用的**文献典型值**（牌号、关键参数、来源类型，如"PC：E=2350 MPa，σy=62 MPa，手册级典型值"）；
2. 给用户三选项：**用此典型值(推荐) / 我提供实测数据 / 先用典型值跑通流程后替换**；
3. 参数本体写进任务书 §2 部件表下方；任务书 §7 强制标注"文献典型值 ≠ 实测，正式结论需复核"。

无人值守：直接取典型值，标 `[假设]`。

### 4.3 关注指标的验收判据（填任务书 §6 时使用）

用户对判据答"你定"时按下表取默认；没有合适默认时**明确允许**写
"如实报告量值，不设合格线，由用户自评"——这也是合法的验收标准写法。

| 关注指标 | 默认判据 |
|---|---|
| 塑性变形/开裂风险 | 等效塑性应变峰值 < 材料断裂应变的 50%（无断裂数据时塑性件取 5% 保守线）→ 低风险；超线则报告位置与量值 |
| 加速度 g 值 | 如实报告峰值与时程，不设线（合格线取决于被保护对象规格） |
| 吸能/峰值力（碰撞） | 如实报告吸能量、比吸能、峰值力；用户有目标值才设线 |
| 穿透判定（侵彻） | 穿/未穿 + 残余速度；剩余厚度 > 0 即未穿 |
| 成形质量 | 减薄率 < 20% [默认]；起皱/回弹如实报告 |
| 流体载荷（ALE/SPH） | 如实报告压力/冲击力时程峰值 |

## 5. 各工况针对性问题库

通用四连问（任何工况先问）：**要仿什么事件？关心什么结果？几何多大？什么材料？**
之后按工况追问：

### 跌落 drop
- 跌落物：质量/尺寸？刚体化（只关心目标物响应）还是变形体（关心跌落物自身损伤）？
- 高度还是初速？姿态（平砸/棱砸/角砸——角砸需要偏置或旋转姿态）？
- 目标面：刚性地面（RIGIDWALL 即可）/ 变形板 / 缓冲材料（泡沫→提示大变形负体积风险）？
- 关注：加速度峰值（g 值，需要 NODOUT）/ 塑性变形 / 是否二次反弹（决定 ENDTIM）？

### 碰撞/压溃 crash
- 碰撞双方与配重：移动物质量、速度？被撞物固定方式？
- 压溃方向与引导：轴向（需要导向约束）还是斜撞？
- 关注：吸能量 / 峰值力（MATSUM+RCFORC）/ 折叠模式？
- 薄壁件自接触默认开（SINGLE_SURFACE），提醒 ELFORM=16 防沙漏。

### 侵彻 penetration
- 弹体：形状（平头/卵形/球）、材料、速度？（>1000 m/s 建议 cm-g-us + dp 复核）
- 靶：材料、厚度、单层/多层、边界（四边固支默认）？
- 关注：穿/不穿判定、残余速度、开坑形貌？（决定侵蚀参数与网格密度）
- 默认技术路线：MAT_015(JC)+EOS+MAT_ADD_EROSION+ERODING 接触。

### 成形 forming
- 工艺：弯曲/辊压/拉深/冲压？工具几何（gen_mesh 可生成平板/块/圆辊等原语，见 §4.1；复杂型面需用户供网格）？
- 行程与速度？（提示：显式准静态会做质量缩放+阻尼，KE/IE<5% 为验收）
- 板料：牌号、厚度？关注：回弹（需要隐式回弹另算，先声明边界）/减薄/起皱？

### ALE（流固/流体）
- 流体：水/空气/其他？域尺寸？初始形态（水柱/液面/射流）？
- 有无结构耦合（纯 S-ALE 流动 vs FSI——FSI 复杂度高一档，需要明确）？
- 关注：波高/压力场/对结构的冲击载荷？
- 提示能量比门槛按 0.2 放宽（对流簿记损耗）。

### SPH
- 粒子物质与形态（水柱/鸟体/冰块）？撞击对象？速度？
- 粒子数预算（默认 3k~10k；更多要提醒耗时）？
- 关注：冲击力时程 / 结构变形？

## 6. 任务书模板（收敛完成后生成 spec.md）

```markdown
# 仿真任务书：<一句话标题>
状态：待用户确认 | 已确认（<日期>）

## 1 工况与目的
<工况类型；要仿真的物理事件；关注的输出指标>

## 2 部件表
| 部件 | 几何/尺寸 | 质量 | 网格来源与密度 | 材料(库名或来源) | 约束 |
|---|---|---|---|---|---|
<库外材料的参数本体附在表下方，标注来源与可信度>

## 3 载荷与初始条件
<重力/初速/强制运动，含方向与数值（注明单位）>

## 4 接触
<配对、类型、摩擦>

## 5 单位制与数值参数
单位制 | ENDTIM | 输出请求与频率（GLSTAT/D3PLOT 必备；按关注指标追加 NODOUT/RCFORC/ELOUT 等）
| 精度(sp/dp) | 预估规模(单元数/单次时长/交付期限)

## 6 验收标准
质检门槛（默认六道 + 本工况放宽项）+ 用户关注指标的合格判据

## 7 假设与默认值清单
每条标 [默认]（用户认可的工程默认）或 [假设]（无人值守时代理自取，需用户复核）
```

## 7. 确认门（强制）

任务书写完先展示给用户，问一句："**按此任务书执行？**"（这是全流程唯一一次强制确认；
用户改哪条就更新哪条再确认）。确认后把 spec.md 存入本次工作目录，阶段 2 开始。
**无人值守时确认门不阻塞**：任务书全部缺项按 §1 取默认标 `[假设]`，直接进入阶段 2。

之后任何环节（阶段 2~5，含修复循环）发现与任务书冲突的事实（材料参数物理不合理、
终止时间明显不够、网格规模超预算），**交互可用时回到用户更新任务书**，不要静默偏离契约；
**无人值守时**按推荐方案处理，把该项升格为 `[假设]`，在最终报告中显著列出提请复核。
最终交付报告（阶段 5）必须逐条对照任务书第 6 节的验收标准给出核对结果。
